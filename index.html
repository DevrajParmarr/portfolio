    NeuroAgent — Autonomous Software Engineering Agent
    
            
    Most engineers use AI as autocomplete. NeuroAgent is different — a fully autonomous multi-agent system that accepts plain English and delivers working, tested, committed code. Built on LangGraph's stateful graph with a ReAct loop: PlannerAgent decomposes tasks → CoderAgent implements with GPT-4/Claude → TestAgent writes and executes tests in a Docker sandbox → ReviewerAgent quality-gates and loops back on failures → DeployAgent commits to GitHub and fires CI/CD. Dual-layer memory: Redis for in-session context, PostgreSQL + pgvector for semantic long-term recall. The React frontend streams each agent's live reasoning via WebSockets.

    Route Optimizer — Fleet Logistics Intelligence Platform
    
            
    
              
    // The problem
    
              
    The Heterogeneous Fleet CVRP (HFCVRP) is NP-Hard. Real logistics companies — Amazon, Zomato, Dunzo — lose millions on suboptimal routing. Most academic solutions exist only on paper. I built a full-stack platform that solves it live on real map data, for 5–100 destinations with 2–50 mixed-capacity vehicles.
    
            
    
          
    
          
    
            Live demo · random stops
            
            
    
              greedy — → 2-opt — 
              
            
    
          
    
          
    
            How it works4 parts · algorithm, API, map, impact
            
    
            
    Algorithmic core
    Modelled fleet dispatch as a Heterogeneous Capacitated VRP, solved with a Clarke-Wright savings heuristic refined by 2-opt local search — with greedy nearest-neighbour as the baseline to beat.
    
            
    Backend engineering
    Modular Node.js/Express REST API with separate endpoints for route computation, ETA estimation and live-location updates; Haversine distances and non-blocking middleware keep the event loop free under large payloads.
    
            
    Interactive map UI
    React + Leaflet.js — define problems directly on the map, then watch live multi-vehicle movement with dynamic re-routing as new location data arrives.
    
            
    Real-world impact
    Cut total route distance by 20% against a nearest-neighbour baseline across 50+ node instances, with graceful fallbacks for overloaded vehicles and isolated stops.
